# Student Management System

## Description
"This project is a student management system build using Python. It allows users to add, display, search, update, delete and sort student records.This project is like a single solution to all the problems faced when managing records of many students in one go.

## Features
- Add new student records
- Display all stored students
- Search for a student by ID or name
- Update existing student information
- Delete student records
- Sort student records
- Topper Details
- Statistics 
- Complete Report

## Technologies Used
- Python
- Git / GitHub
- VS Code
- Text file (for storing student records)

## project Structure
File                 Purpose

student.py           Contains the Student class and student-related data
file_handler.py      Handles loading and saving student data
students.txt         Stores the student records

## How to Run
1. Clone the repository
git clone <https://github.com/BaseraSultana/Student-Management-System.git>
2. Open the project folder
cd StudentManagementSystem
3. Run the program
python main.py

## How It Works
The program starts from 'main.py', which handles the menu and controls the main flow of the application.
The 'Student' class in 'student.py' represents each student and stores their details.
The 'file_handler.py''module handles loading student records from 'students.txt' and saving changes back to the file.
The student objects are kept in a list while the program is running. Operations such as adding, updating, deleting, searching, and sorting work on the list.
